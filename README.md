# ChurchRides legal pages

Public pages for the ChurchRides app, published with GitHub Pages:

- Privacy Policy: `privacy/index.html`
- Terms of Service: `terms/index.html`
- Support: `support/index.html` (App Store Connect's Support URL)

The app links here from Settings (`AppLinks.privacyPolicy`, `AppLinks.termsOfService`), and App Store Connect uses the privacy and support URLs.
